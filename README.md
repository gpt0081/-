# 눈가리고아웅판별기 · 대한민국 정치인 실록

> **눈 가리고 아웅. 기록은 눈을 감지 않는다.**

대한민국 정치인의 과거 발언, 공약, 표결, 정책 행동, 행정·입법·사법 관련 기록, 해명과 사건 관계를 시간순으로 연결해 사용자가 직접 원문과 앞뒤 맥락을 검토할 수 있게 하는 **정치 기록 추적·디지털 실록 프로젝트**입니다.

## 최상위 목적

이 프로젝트의 최종 대상은 역대 대통령만이 아니라 **대한민국 정치사의 주요 정치인 전체**입니다. 대통령은 조사 순서를 잡기 위한 첫 번째 backbone이자 초기 코퍼스일 뿐입니다.

대통령을 조사하면서 등장하는 국무총리, 장관, 국회의원, 정당 지도부, 지방자치단체장, 정부수립기·독립운동기 주요 정치인을 독립된 인물 노드로 축적합니다. 사건 역시 특정 대통령 파일 안에 묻지 않고 정치인·기관·정당·법률·정책·의사결정·집행·반대·후대 판단을 연결하는 독립 사건 노드로 관리합니다.

현재 `data/presidents.json`은 대통령 backbone을 유지하고, `data/politicians.json`은 전체 정치인 registry, `data/events.json`은 사건 cross-link registry 역할을 합니다. 기존 대통령 중심 ID와 파일은 깨뜨리지 않고 `legacyIds`와 연결 필드로 점진적으로 일반화합니다.

## 핵심 원칙

**AI가 정치인을 심판하지 않습니다.** 시스템은 관련 기록을 공격적으로 찾되 공개·확정은 보수적으로 처리합니다. 원문·날짜·당시 맥락·후속 설명·반증·불확실성을 함께 보여주고 최종 판단은 사용자에게 남깁니다.

- 1차 자료와 동시대 기록 우선
- 주장과 사실, 정치적·법적·행정적 책임, 직접 명령을 분리
- 발언 일부만 잘라 쓰지 않고 원문 문맥 보존
- 상반 자료와 반증을 별도로 탐색
- 비교 후보는 제시하되 자동적인 위선·선악·추천·순위 판정 금지
- 정치 성향·정당과 무관하게 동일한 데이터 규칙 적용
- 오류 정정, 반론, CONFLICTED/BLOCKED/REOPENED 이력 보존
- 모르는 것은 지우지 않고 역사부채로 관리

## 조사 모델

일반 시간별 조사에서는 현재 핵심 인물의 고우선순위 미해결 단서 2~4개를 추적하고, 논란과 무관한 일반 국정 영역도 최소 1개 보강합니다. 조사 중 중요하게 등장한 다른 정치인은 단순 이름이 아니라 사건·직책·정당·정책·갈등·협력 관계와 함께 candidate politician graph에 연결합니다.

조사 사슬은 가능한 범위에서 `검색어 확장 → 2차 자료에서 원문 단서 추출 → 공식/1차 아카이브 역추적 → 날짜·인물·기관·사건명 변형 검색 → 상반 자료 탐색 → 원문 교차검증 → 새 인물/사건/문서 단서 생성`을 반복합니다.

한 대통령/시대의 모든 open lead가 사라질 때까지 기다리지 않습니다. 주요 국정영역과 핵심 사건·행위자에 충분한 1차자료 기반 골격이 형성되면 미해결 블랙박스는 `HISTORY_DEBT`와 인물별 open leads에 보존하고 chronological frontier를 다음 시대로 전진시킵니다. 그렇지 않으면 역사 연구의 특성상 끝없이 생기는 세부 질문 때문에 첫 backbone에 고착될 수 있습니다.

역사부채 전체 전수 재조사는 매시간 반복하지 않고 **매주 일요일 첫 조사 회차에 1회** 수행합니다. 단, 평상시 조사에서 역사부채를 해결하거나 흔드는 새 증거가 발견되면 즉시 갱신합니다.

## 데이터 구조

- `data/politicians.json`: 전체 정치인 stable ID, 이명, 직책, 조사상태와 연결
- `data/events.json`: 사건 stable ID와 정치인·기관·정당·정책 cross-link
- `data/presidents.json`: 대통령 임기순 backbone
- `data/evidence/`: 인물별 증거 원장
- `data/annals/`: 인물별 디지털 실록
- `data/research/`: coverage, open leads, HISTORY_DEBT
- `docs/`: 방법론, 아키텍처, 조사 루프

## 운영 원칙

> **수집은 공격적으로, 공개는 보수적으로.**
>
> **GitHub에서 충분히 축적하고, Floot는 묶어서 빌드한다.**

수동 GPT 조사 루프의 결과는 먼저 GitHub의 `data/`, `docs/`, `sql/`에 축적합니다. 조사 1회마다 Floot를 다시 빌드하지 않습니다. Floot는 충분한 조사 묶음과 의미 있는 스키마/UI 변화가 쌓이고 사용자가 별도로 요청했을 때만 반영합니다.

## 현재 상태

이승만·제1공화국은 초기 심층 코퍼스의 골격을 확보한 상태로 보고, 남은 블랙박스는 `HISTORY_DEBT`와 open leads에서 계속 관리합니다. **현재의 주 연구 frontier는 4·19 이후 과도정부와 윤보선·장면의 제2공화국(1960~1961)으로 전진했습니다.**

제2공화국은 대통령 윤보선을 chronological backbone으로 사용하되 내각책임제의 실제 행정부 중심인 국무총리 장면을 동등하게 중요한 독립 정치인 노드로 병행 조사합니다. 허정 과도정부, 제3·4차 개헌, 7·29 총선, 민주당 신·구파와 정부 구성, 부정선거 사후처리, 경제개발·국토건설, 한미관계와 사회운동, 군 인사와 5·16을 사건망으로 확장합니다. 5·16 전환부가 충분히 구조화되면 박정희 시대를 다음 chronological frontier로 삼습니다.

세부 설계는 `docs/ARCHITECTURE.md`, `docs/HOURLY_ANNALS_LOOP.md`, `docs/RESEARCH_LOOP.md`, `docs/METHODOLOGY.md`, `docs/FLOOT_BUILD_POLICY.md`를 참고하세요.
