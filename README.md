# 눈가리고아웅판별기

> **눈 가리고 아웅. 기록은 눈을 감지 않는다.**

정치인의 과거 발언, 공약, 표결, 정책 행동, 해명을 시간순으로 연결해 사용자가 직접 앞뒤 맥락을 검토할 수 있게 하는 정치 기록 추적 웹앱입니다.

이 프로젝트의 핵심 원칙은 **AI가 정치인을 심판하지 않는 것**입니다. 시스템은 관련 기록을 찾아 연결하고, 원문·날짜·당시 맥락·후속 설명을 함께 보여줍니다. 최종 판단은 사용자에게 남깁니다.

## MVP

- 정치인/쟁점/발언 통합 검색
- 과거 기록 ↔ 현재 기록 비교
- 시간순 타임라인
- 원칙/주제 태그
- 원문 출처와 문맥 표시
- 당사자의 해명·예외 사유 병렬 표시
- 수정 이력과 반론을 고려한 데이터 모델
- 자동 점수/순위/정치적 판정 없음

## 개발 원칙

1. 1차 자료 우선: 국회 회의록, 정부·정당 공식 문서, 당사자 영상/게시물 등
2. 주장과 사실 분리
3. 발언 일부만 잘라 쓰지 않고 원문 문맥 보존
4. 비교 후보는 제시하되 '내로남불 확정' 같은 자동 판정 금지
5. 정치 성향·정당과 무관하게 동일한 데이터 규칙 적용
6. 오류 정정과 반론 경로를 제품의 핵심 기능으로 취급

## 현재 상태

첫 MVP는 데모 데이터로 UI와 비교 흐름을 검증합니다. Floot 버전에는 Postgres 기반 evidence ledger와 GPT Research Loop가 연결되어 있습니다.

> **수집은 공격적으로, 공개는 보수적으로.**

연구 루프는 3시간마다 enabled 실존 target을 순환 검색하며, gpt-5.6-luna의 web search로 공개 기록 후보를 수집합니다. 검색 결과는 곧바로 공개되지 않고 `research_candidates(status=pending)`에만 적재됩니다. 사람의 검토를 통과한 자료만 records/sources 및 comparison 후보로 승격하는 구조입니다.

세부 설계는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)와 [docs/RESEARCH_LOOP.md](docs/RESEARCH_LOOP.md)를 참고하세요.
