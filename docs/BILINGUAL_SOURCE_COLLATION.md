# 원문·번역 병렬 검증

- 번역은 원문과 독립된 증거로 중복 계산하지 않는다.
- 수치·단위·상한/하한·부정문·주체·결정/집행 동사를 직접 대조한다.
- 불일치 시 양쪽 URL, 정확한 충돌점, 영향받는 주장·사건, 다음 원문 표적을 기록한다.
- 기존 설명을 조용히 바꾸지 말고 correction/review history를 남긴다.
- FRUS에서 당사자 서한이 요약만 수록되면 서한 원문을 직접 확인한 것으로 기록하지 않는다.
- 목표·계획·예산·승인·실제 집행을 구분한다.

실제 대조: FRUS 1949 d300 항공기 기종 변경 방향, FRUS 1951 d332 환산가격 6000원 하한/상한. 자세한 기록: data/claims/run108-frus-translation-audit.json.
