# 편집·검증 방법론

## 목적

눈가리고아웅판별기는 특정 정치인이나 정당에 대한 찬반 결론을 대신 내리지 않는다. 서로 다른 시점의 기록을 연결해 사용자가 직접 일관성, 상황 변화, 예외 사유를 검토하도록 돕는다.

## 기록 단위

각 Record는 최소한 다음 필드를 가진다.

- subject: 발언/행동의 주체
- occurredAt: 발생 시점
- kind: 발언, 공약, 표결, 법안, 정책, 임명, 해명 등
- topic: 주제
- quoteOrAction: 직접 인용 또는 행동의 사실 서술
- context: 당시 상황
- source: 원문 주소와 출처 유형
- sourceGrade: 1차/2차 자료 구분
- capturedAt: 시스템 수집 시각

## 비교 단위

두 기록이 같은 주제 또는 같은 규범적 기준을 다룬다고 판단될 때 Relation을 만든다. Relation은 판정이 아니라 검토 후보이다.

- recordA / recordB
- 연결 근거
- 공통 주제
- 달라진 조건
- 당사자의 설명
- 반론 및 추가 근거
- 검토 상태

## 금지하는 자동화

- 정치인별 위선 점수
- 정당별 일관성 순위
- 선거 후보 추천 또는 반대
- 출처 없는 요약을 사실처럼 표시
- 문맥을 제거한 짧은 인용만으로 결론 생성

## 출처 우선순위

1. 법령, 판결문, 국회 회의록, 표결 기록
2. 정부·지자체·정당 공식 문서
3. 당사자 공식 영상·SNS·기자회견 원문
4. 복수의 신뢰할 수 있는 언론 보도
5. 해설·칼럼·커뮤니티는 보조 자료로만 사용

## 핵심 질문

사이트는 결론 대신 다음 질문을 보여준다.

- 두 기록에서 같은 원칙이 적용되는가?
- 당시 사실관계와 법적 조건은 무엇이 달랐는가?
- 당사자는 입장 변화의 이유를 설명했는가?
- 상대 진영이 같은 예외를 주장했을 때도 같은 기준을 적용했는가?
- 원문 전체를 읽어도 비교가 유지되는가?
