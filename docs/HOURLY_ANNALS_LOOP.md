# Hourly Korean Politician Annals Research Policy

## 목적

최종 목표는 대통령만의 실록이 아니라 **대한민국 역대 정치인 전체의 검증 가능한 디지털 실록**이다. 대통령 임기순 조사는 초기 backbone이지만 연구의 기본 좌표계가 아니다. 전체 연구 좌표는 `docs/KOREA_POLITICAL_FOREST.md`의 **시대 × 구조층** 매트릭스를 따른다.

대통령 조사에서 등장하는 비대통령 정치인과 사건을 독립 노드로 축적하는 것에 그치지 않고, 국회·정당·관료·사법·군·경찰·정보기관·지방정치·정치경제·노동·시민사회·언론·사회균열·외교안보 같은 비대통령 구조를 독립 연구선으로 병행한다.

## Forest-first 원칙

연구 순서는 기본적으로 다음과 같이 둔다.

`시대/체제 → 제도 → 기관 → 정치·사회 세력 → 균열/정책영역 → 사건 → 행위자 → 문서 → 주장/반증`

`대통령 → 주변인물 → 사건`만을 반복하는 방식은 행정부와 중앙정치의 과대표집을 만들 수 있으므로 전체 지형을 확인하는 보조선으로만 사용한다.

전국 coverage의 기본 단위는 `시대 × 구조층` 셀이다. 상태는 `UNMAPPED → SEEDED → STRUCTURED → VERIFIED / DEBT_TRACKED`를 사용한다. 정치인 개인의 `DISCOVERED → IDENTIFIED → VERIFIED → ANNALS_ACTIVE → MATURE` 상태와 혼동하지 않는다.

초기 전국 목표는 특정 시대의 완전성이 아니라 **모든 시대·구조층을 최소 SEEDED까지 빠르게 지도화하는 것**이다. 그 뒤 여러 구조층을 연결하는 사건과 인물을 깊게 검증한다.

## 매 실행 순서

1. README, `docs/KOREA_POLITICAL_FOREST.md`, 최근 commit/issues/PR, `data/presidents.json`, `data/politicians.json`, `data/events.json`, 관련 evidence/annals/open-leads/coverage, `data/research/HISTORY_DEBT.md`와 방법론 문서를 먼저 읽는다.
2. 직전 run report와 lead queue를 확인하고 이미 해결된 사실을 기계적으로 반복 검색하지 않는다.
3. 현재 심층 연구선의 고우선순위 미해결 단서를 추적하되, 동시에 전국 forest map에서 아직 `UNMAPPED` 또는 얕은 `SEEDED` 상태인 다른 시대·구조층을 넓힌다.
4. 한 인물이나 한 대통령의 세부 질문이 무한히 늘어나면 모든 질문을 해결하려 머물지 않는다. 핵심 구조가 잡힌 뒤 나머지는 history debt/open lead로 보내고 빈 구조층으로 이동한다.
5. 조사 중 새로 중요하게 등장한 정치인뿐 아니라 관료·법조인·군인·사회운동가·경제단체·언론·기관도 적절한 노드 유형으로 연결한다. 단순 이름이 아니라 사건·직책·조직·정책·갈등·협력 관계와 후속 조사 가치를 기록한다.
6. `검색어 확장 → 2차 자료의 원문 단서 → 공식/1차 아카이브 역추적 → 날짜·인물·기관·사건명 변형 → 반증 검색 → 원문 교차검증 → 새 단서 생성`을 가능한 범위에서 반복한다.
7. 한국어 외에도 유효하면 영어·한자·과거 인명 표기·로마자 변형을 사용한다.
8. 공식 1차 자료, 동시대 문서, 법령, 판결문, 국회·정부·대통령기록, 선거기록, 공식 진상조사, 관보, FRUS 등 해외 공식 기록을 우선한다.
9. 언론·논문·전기·회고록은 원문 위치를 찾거나 맥락을 보강하는 데 사용하며 중대한 사실을 단독 확정하지 않는다.
10. 새 증거는 출처·접근일·날짜·주체·기관·행위·맥락·반론·불확실성과 함께 원장에 기록한다. 상충 자료는 지우지 않는다.
11. 해결되지 않는 질문은 역사부채에 등록하거나 상태를 갱신한다.
12. 확정 사실, 당사자 주장, 정부·기관 행동, 동시대 외부 관찰, 후대 판결·진상조사, 정치적·법적·행정적 책임, 직접 명령을 서로 다른 층위로 기록한다.

## 전체 숲의 구조층

세부 정의는 `docs/KOREA_POLITICAL_FOREST.md`를 기준으로 하며, 모든 시대에서 다음을 확인한다.

1. 헌정질서
2. 국회·입법
3. 정당·정파
4. 선거·대표성
5. 행정부·관료제
6. 사법·헌법재판·검찰
7. 군·경찰·정보기관
8. 지방정치·지방행정
9. 정치경제
10. 노동·농민·직능·기업
11. 복지·사회정책
12. 시민사회·사회운동
13. 언론·공론장
14. 지역·계층·세대·젠더 균열
15. 외교·안보·분단
16. 정치자금·부패·정경관계
17. 과거사·전환기 정의

## 역사부채 주간 전수조사

전체 역사부채를 매시간 재검색하지 않는다. **매주 일요일 Asia/Seoul 기준 그날의 첫 실행에서만** `OPEN`, `NARROWED`, `BLOCKED`, `CONFLICTED`, `REOPENED` 전 항목을 전수 재조사한다. 대통령뿐 아니라 registry에 등록된 모든 정치인·사건의 부채를 포함한다.

- `last_full_review` 또는 동등한 기록으로 같은 일요일 중복 실행을 막는다.
- 새 디지털화 문서, 기록물 해제, 판결·국회·정부 기록 공개, 해외 외교문서, 새 학술연구, 회고록 원문, 아카이브 접근상태 변화를 확인한다.
- `BLOCKED`도 공개·디지털화·접근상태 변화를 확인한다.
- `RESOLVED`는 기본 전수대상에서 제외할 수 있으나 새 증거가 기존 결론을 흔들면 `REOPENED`로 되돌린다.
- 일반 시간별 조사 중 역사부채를 해결·축소·반박할 새 자료가 나오면 일요일을 기다리지 않고 즉시 갱신한다.

## 정치인 중심 확장 규칙

- 모든 정치인은 stable ID를 가진 독립 노드다. 대통령 여부는 역할 속성이지 데이터 모델의 상위/하위 관계가 아니다.
- 기존 대통령 ID와 파일은 `legacyIds`와 연결 필드로 migration 가능하게 유지한다.
- 사건도 stable ID를 가진 독립 노드로 만들고 관련 정치인·기관·정당·법률·정책·결정·집행·반대·결과·후대판단을 cross-link한다.
- 동일 사건에서 누가 제안·결정·집행·반대했는지와 당시 법적·제도적 권한을 구분한다.
- 대통령 재임 중 발생했다는 이유만으로 대통령 직접 지시로 귀속하지 않는다.
- 인물 조사 우선순위는 정치적 호불호가 아니라 역사적 영향 범위, 공직 수준, 제도 변화 관여, 주요 사건 관여, 자료 연결 중심성으로 정한다.

## 대통령 backbone의 위치

대통령 임기순 backbone은 **시간 탐색 보조선**으로 유지한다. 현재까지 만들어 둔 이승만·제1공화국, 제2공화국 및 이후 대통령 관련 자료는 폐기하지 않는다.

다만 다음 시대로 이동하는 기준을 더 이상 '현재 대통령 파일의 완성도'로만 결정하지 않는다. 대통령 관련 미해결 사항이 남아도 전국 forest map의 다른 시대·구조층이 비어 있으면 breadth-first 지도화를 우선할 수 있다.

비대통령 정치인 조사는 대통령 순회가 끝난 뒤 시작하는 2단계가 아니다. 반복 등장하는 정치인은 registry와 사건 그래프에 축적하고, 충분한 evidence가 쌓이면 독립 annals로 승격한다.

## 중립성

정당·이념·호감도와 관계없이 동일한 자료 규칙을 적용한다. 정치인을 평가·추천·반대·순위화하지 않는다. ‘위선’, ‘독재자’, ‘영웅’, ‘좋은/나쁜 정치인’ 같은 평가를 시스템의 독자적 결론으로 저장하지 않는다. 모순 가능성을 보여주는 기록과 일관성을 보여주는 기록을 같은 기준으로 수집한다.

시대구분 자체도 단일한 역사해석으로 확정하지 않는다. ‘48년 체제’, ‘61년 체제’, ‘87년 체제’, ‘97년 체제’ 같은 학술적 분석틀은 해당 연구자의 해석으로 연결하고 다른 시대구분과 비교한다.

## 실행 보고

매 실행 종료 시 다음을 우선 보고한다.

- 어느 `시대 × 구조층` 셀을 새로 SEEDED/STRUCTURED/VERIFIED 했는지
- 새 확인 사실·문서와 provenance
- 새 사건·기관·조직·인물 연결
- 반증/충돌자료와 좁힌 미해결 질문
- 역사부채 변경 여부
- 실제 수정 파일과 GitHub commit SHA
- 다음 전국 forest 공백과 심층 lead

주간 전수조사일이 아니면 `역사부채 주간 전수조사 미실시`를 명시한다. 진전이 없으면 억지 결론 대신 확인한 기관·검색어·문서와 막힌 이유를 기록한다.
