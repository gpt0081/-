# Hourly Annals Research Policy

## 목적

대한민국 역대 대통령을 임기 순으로 한 사람씩 조사해, 단순 요약이 아니라 출처·맥락·반론·미해결 연결고리까지 보존하는 디지털 실록을 만든다.

## 매 실행 순서

1. `data/presidents.json`에서 현재 조사 중인 대통령을 확인한다.
2. 해당 인물의 `data/evidence/`, `data/annals/`, `data/research/*open-leads*`, `data/research/HISTORY_DEBT.md`를 먼저 읽는다.
3. 이미 해결된 사실을 반복 검색하지 않는다.
4. 가장 높은 우선순위의 미해결 단서 1~2개와, 조사 커버리지에서 비어 있는 일반 국정 영역 1개를 선택한다.
5. 공식 1차 자료, 당시 문서, 법령, 판결문, 국회·정부·대통령기록, 해외 외교문서, 공식 진상조사 자료를 우선 검색한다.
6. 언론·논문·회고록은 1차 자료 위치를 찾거나 맥락을 보강하는 데 사용하고, 단독 근거로 확정하지 않는다.
7. 새 증거가 나오면 GitHub 원장을 갱신하고 출처·날짜·주체·기관·행위·맥락·반론·불확실성을 구조화한다.
8. 해결되지 않는 질문은 삭제하지 않고 역사부채에 등록하거나 상태를 갱신한다.
9. **매 실행마다 HISTORY_DEBT의 모든 미해결 항목을 전수 재조사한다.** 일부 샘플만 확인하거나 오래된 항목 몇 개만 순환 조사하지 않는다. 각 항목마다 새 디지털화 문서, 기록물 해제, 판결문 공개, 해외 외교문서 공개, 새 학술연구·원문 아카이브 출현 여부를 확인하고, 진전이 없어도 마지막 재조사일·검색경로·막힌 이유를 갱신한다.
10. 확정·추론·당사자 주장·외부 관찰·후대 판단을 서로 다른 층위로 기록한다.
11. 한 인물의 고우선순위 공백이 대부분 좁혀지고 주요 국정 영역이 충분히 채워지면 다음 대통령으로 넘어간다. 단, 역사부채는 닫지 않으며 **후속 대통령을 조사하는 동안에도 매 실행마다 전체 역사부채를 전수 재조사한다.**

## 중립성

- 정당·이념·호감도와 관계없이 동일한 자료 규칙을 적용한다.
- 정치인을 평가·추천·순위화하지 않는다.
- ‘위선’, ‘독재자’, ‘영웅’ 같은 평가어를 시스템의 독자적 결론으로 저장하지 않는다.
- 같은 자료가 일관성을 보여주면 그것도 수집한다.
- 정치적 책임, 법적 책임, 행정적 책임, 직접 명령은 서로 다른 개념으로 기록한다.
- 후대 판결·진상조사는 당시의 직접 증거와 구분한다.

## 종료가 아니라 전환

한 대통령을 ‘완료’로 봉인하지 않는다. 현재 가능한 범위의 실록이 충분히 형성되면 다음 대통령으로 이동하고, 남은 블랙박스는 역사부채로 계속 살아 있게 둔다.
