# 역사자료 날짜·인물·명령 귀속 감식 규칙 (run124)

1. `event_date`, `document_date`, `publication_date`, `retrospective_period`, `archive_access_date`를 구분한다. 국사편찬위원회 일별 색인에 월간 회고가 섞여 있으므로 색인 날짜만으로 사건일을 확정하지 않는다.
2. 후대 선거 당선인 목록의 정당 표기를 당선일 당적으로 자동 소급하지 않는다. 선거 당시 원당선공고와 이후 당적 변경·보궐선거를 분리한다.
3. 법안 제출, 위원회 심사, 본회의 심의보류, 국회 가결, 정부 공포, 시행, 집행은 서로 다른 사건이다. 1951-12-21 귀속재산법 90:0은 **심의보류 동의**의 표결이다.
4. 군사법원 판정 이유의 명령권자 책임과 현장 집행자의 범위초과 책임을 별도 action으로 기록한다. 대통령 재임 중 발생했다는 사실로 직접 명령을 추정하지 않는다.
5. 수치 자료는 단위·기준시점·모집단·산술을 검증한다. 내부 계산 불일치는 원면 대조 전 전사/인쇄 오류 가능성을 보존한다.
6. 신문 전사문, 원지면, 정부 원공문, 외교문서 번역, 후대 기관 연혁, 색인만 확인한 PDF를 각각 다른 `access_state`와 `provenance`로 기록한다.
7. 발표·예정·제안·합의 보도와 실제 집행·지급·치료·수출·판결을 혼동하지 않는다. 당사자 진술은 확인된 법적 사실로 승격하지 않는다.
