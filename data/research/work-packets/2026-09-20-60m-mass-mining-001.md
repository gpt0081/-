## Evidence discipline
각 line은 VERIFIED / NARROWED / BLOCKED / CONFLICTED / QUEUED 중 하나로 남긴다. 대통령 재임 중 사건이라는 이유만으로 직접 지시를 귀속하지 않는다. 동시대 당사자 주장, 기관행위, 후대 판결/조사, 직접명령을 분리한다.


## Strategy revision after timing audit
사용자 실측상 이전 kickoff가 1분43초에 불과했다. 따라서 '패킷을 만들었다=60분급 실행'으로 간주하지 않는다.

### New execution rule
1. 계획 생성은 progress count에서 제외.
2. GitHub 첫 커밋을 종료 신호로 사용하지 않는다. 서로 다른 광맥을 여러 차례 검색·원문검증한 뒤 batch checkpoint한다.
3. 각 search batch는 최소 8~10개의 서로 다른 research line을 동시에 건드린다.
4. 한 광맥에서 source가 나오면 바로 인접한 반증/상위명령/하위집행/후대판단을 다시 검색한다.
5. 현재 응답이 끝나도 packet은 ACTIVE이며, 미완료 research line은 삭제하지 않는다.
6. '60분 완료'라는 표현은 실제 사용자 관측시간 또는 이에 준하는 충분한 연속 tool-work가 확인되기 전 사용하지 않는다.
