# Run report — Politician Network Pass 59

Date: 2026-09-22
Focus: Robertson mission의 협상 후반부, 상호방위조약 문안, 포로/UNC 지휘 이행, 1953-07-09 이승만 서한의 armistice non-obstruction threshold

## Result
직전 pass 58의 6/18~25 위기 재구성에 이어 FRUS Korea XV pt.2 d646~d685를 연속 40건 직접 열람했다. 핵심 교정은 `Robertson mission = 하나의 합의`라는 평면적 서술을 버리고, 한국측 aide-memoire 제출 → 미국측 거부/수정 → 이승만 직접서한 → 방위조약 문안 교환 → POW/UNC 이행협의 → 불완전하지만 armistice 진행에 충분한 7/9 서한이라는 문서 상태기계로 보는 것이다.

변영태와 백두진의 역할도 갈라졌다. d676의 `변영태가 7/7 aide-memoire를 작성했다`는 내용은 Robertson의 동시대 판단이므로 claim으로 유지하고 한국측 초안/결재선 확보 전에는 확정하지 않는다. 반면 d679은 백두진이 변영태 없이 Robertson–Rhee 단독면담을 제안했다고 보고해 협상채널 조정 행위를 별도로 구조화할 근거가 된다.

또한 d677/d685를 함께 보면 `ROKA는 UNC 지휘에 남는다`와 `ROK 정부가 armistice를 완전히 지지한다`, `UNC가 ROK를 무력으로 강제할 수 있다`는 서로 다른 명제다. 이 세 층을 합치지 않는다.
