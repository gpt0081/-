# Pass 171 execution report — 임시특별부의 행정 흔적을 좁히다

## 실질 진전

이번 회차는 pass 170의 `1950년 4월 임시특별부 실제 가동` 충돌을 해결하기 위해 원문 회수 경로를 더 좁혔다. 재판관 5인의 실명과 실제 판결 1건 원문을 이번에도 확보하지 못했으므로 해당 명제는 `CONFLICTED_PENDING_PRIMARY`로 유지한다. 검색결과 부재를 부존재 증거로 사용하지 않는다.

대신 법률 제78호 자체에서 실제 운영 여부를 검증할 수 있는 새로운 행정 흔적을 분리했다. 이 법은 재판관 5인뿐 아니라 서기관 5인·서기 5인을 두고, 1949년도 반민족행위특별재판부 예산을 임시특별부가 인계받도록 했다. 따라서 실제 가동 여부는 재판관 임명만 찾을 문제가 아니다. `재판관 인사발령 + 서기관/서기 임명 + 예산 인계·집행 + 사건대장 + 공판기일부`가 서로 독립적인 검증축이 된다.

국가법령정보센터의 법률 제54호 개정이유도 다시 확인했다. 1949년 10월4일 특별조사위원회·특별검찰부·특별재판부 관련 조항을 삭제하면서 **현재 계속중인 사건은 단심으로 대법원에서 처리**하도록 하는 것이 개정 목적에 명시돼 있다. 따라서 10월4일은 모든 반민사건의 법적 소멸일이 아니라 기존 특별기구 폐지와 대법원 이관의 전환점이다.

1951년 종점도 한 단계 좁혔다. 국가기록원 발간 연구는 1951년 2월8일 국무회의에서 `임시조직법` 폐지를 논의했다고 지목한다. 국가법령정보센터 법률 제176호는 2월14일 제3·13·34·54호와 제78호를 폐지하고 계속중 공소를 취소된 것으로 보며 기존 판결의 언도 효력을 상실시켰다. 다음 회차에는 2월8일 국무회의록 원문을 직접 열어 제안 부처·국무위원·의결 내용을 확정해야 한다.

## 불확실성 보존

국사편찬위원회 헌정사 DB의 `제78호는 순전히 형식적인 조치`라는 평가는 그대로 보존한다. 같은 기관 우리역사넷의 `1950년 4월 재판부 설치·재판 재개·미결자 중 1명 판결` 서술도 보존한다. 후자의 사건번호·피고인·판결문·재판관이 나오기 전까지 어느 쪽도 최종 승자로 만들지 않는다.

법률 제176호 부칙이 계속중 공소와 기존 판결을 별도로 처리했다는 것은 확정할 수 있지만, 이것만으로 1951년 2월14일 실제 미결사건 수나 유효판결 수를 역산하지 않는다. 실제 사건대장과 종결기록이 필요하다.
