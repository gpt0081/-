# Run 22 report — 2026-10-04

## Focus
Run 21의 교육 연구선을 원문 중심으로 좁혔다. 핵심은 교육법을 `대통령/문교부 정책` 한 덩어리로 쓰지 않고 `문교부 선행안 → 국회 문교사회위원회 → 외부 전문위원 재기초 → 본회의 다회 독회·축조심의·표결 → 법률 공포 → 1952 시행령·지방집행`의 행위자 사슬로 분해하는 것이다.

## 새로 확인·구조화한 핵심
- 1949-08-22 국회 문교사회위원회 최종심사회에는 현상윤·장이욱·오천석·백낙준·최규동 등이 참여했고, 백낙준·오천석·장이욱·현상윤·유진오 5인이 새 교육법안을 기초했다. 이는 교육법을 안호상 또는 이승만 개인의 단독 설계로 귀속하는 설명을 직접 약화한다.
- 국회안은 시·군 단위 교육구, 교육위원회, 교육감, 교육재정, 공민학교·성인반을 포함했다. 평시 지방행정·재정·사회교육 영역을 하나의 사건에서 분리해 구조화했다.
- 1949-10-31 동시대 기록은 문교부안(6·3·3·4)과 국회안의 학제·교육자치 차이를 상세히 남긴다. 안호상뿐 아니라 문교부 총무과장 송재수, 교육계 원로 현상윤, 문교사회위원장 이영준이 서로 다른 위치의 행위자로 등장한다.
- 국회도서관의 1949-11-24 제5회 제49차 공식 회의록 메타데이터에서 대한민국교육법안 제2독회와 30명 이상의 발언자를 직접 확인했다. 이영준·안호상·윤치영·임영신·김봉조·진헌식·조헌영·서우석 등은 재사용 가능한 정치인 노드다.
- 11월 24일 학제, 11월 25일 교원 신분·교육세·보조금 등 축조심의가 이어졌고 11월 26일 동시대 보도는 교육법안이 완전 통과된 상태라고 기록한다.
- 법률 제86호는 1949-12-31 제정·시행됐다. 1952-04-23 대통령령 제633호 교육법시행령은 별도의 행정부 집행단계다.
- 국가기록원 기록물 가이드는 교육법시행령 원철에 법제처장의 공포요청, 이승만 대통령 이하 국무위원의 공포 승인서, 법령 심의승인표, 시행령안이 존재하고 기록물 식별번호 1A00614174533375임을 알려준다. 다음 회차의 가장 가치 높은 원문 표적이다.

## adversarial checks
1. `교육법은 문교부가 만든 법을 국회가 통과시켰다` → 반증: 국회 위원회가 외부 전문가 5인에게 새 초안을 맡긴 기록 확인.
2. `교육법은 안호상 교육철학의 법제화다` → 부분 반증: 문교부안과 국회안 사이 학제·교육자치 쟁점이 컸고 국회가 독립적으로 재기초.
3. `교육법은 대통령의 직접 설계다` → 이번 원문군에서 대통령의 초안 작성·직접 지시 증거 없음. 공포/시행령 승인과 입법기초를 분리해야 함.
4. `교육자치는 1952년에 처음 설계됐다` → 반증: 1949 국회안에 교육구·교육위원회·교육감 구조가 이미 존재.
5. `성인교육은 후대 정책이다` → 반증: 1949 국회안에 공민학교·고등공민학교·성인반이 법제화 대상으로 존재.
6. `1949 교육법 심의는 학제만의 논쟁이었다` → 반증: 11월 25일 교원 신분보장·교육세·보조금 축조심의 확인.
7. `1950 의무교육 시행과 1954~1959 6개년계획은 같은 계획의 단순 연장이다` → 반증 신호: 국가기록원은 전쟁 중단과 1952 시행령 이후의 전후 6개년계획을 별도 단계로 설명.
8. `교육법 최종 내용은 행정부안과 동일했다` → 반증: 8월 국회안과 10월 대립 기록에서 제도·학제 차이가 확인됨. 정확한 조문 diff는 OPEN.
9. `교육법 입법의 핵심 행위자는 장관과 위원장 두 명뿐이다` → 반증: 공식 회의록 발언자 명단과 전문위원 5인 확인.
10. `교육법 시행령은 단순 기술규정이라 대통령/국무위원 행위자 분석이 불필요하다` → 반증 신호: 국가기록원은 대통령 이하 국무위원 공포 승인서와 법령심의승인표 보존을 명시.
