# Politician Network Pass 105 — Peace Line enforcement / 포획심판령

Date: 2026-09-23
Focus: Pass 104의 1952-01 선언 단계에서 1952-10 포획심판 제도화로 이동하여 `선언 -> 나포 -> 조사 -> 심판 -> 집행 -> 사후 국회승인`의 법적·행정적 사슬을 공식 원문 계열로 구조화한다.

## 직접 확인한 핵심 원문

### 1. 대통령기록관 복원기록물
대통령기록관은 이승만 정부 긴급명령철을 설명하면서 긴급명령 문서가 일반적으로 `국무회의 의결문 -> 긴급명령 법조문 -> 국회 승인요청문`으로 구성되고, 국무회의 의결 뒤 공포한 다음 국회에 사후승인을 요청한 구조라고 설명한다. 같은 컬렉션에 `긴급명령제12호-포획심판령`(1952-10-04)과 `포획심판령승인에관한건`(1954-04-07)이 별도 원문으로 존재한다.

이 점은 포획심판령을 단순한 대통령 개인의 해상단속 지시로 환원하지 않고, 국무회의·대통령·국회가 연결되는 헌정적 절차 객체로 다뤄야 함을 뜻한다. 다만 이번 회차에서는 복원 PDF 자체가 웹 fetch에서 cache miss가 발생해 서명자·국무회의 회차·승인문 전문은 미확보 상태다.

### 2. 국가기록원 관보 원문 메타데이터
국가기록원은 `포획심판령(긴급명령제12호)`을 관리번호 `BA0186100`, 관보 제752호(1952-10-04), 총무처 법무담당관 생산, 4쪽 공개 기록으로 식별한다. 같은 국가기록원 주제 목록은 동일 관리번호 계열에 `포획심판소및고등포획심판소개설에관한건(대통령령제707호)`도 수록한다.

### 3. 동북아역사재단 한일회담외교문서의 포획심판령 전문
1952-10-04 긴급명령 제12호 전문에서 다음 제도구조를 직접 확인했다.

- 제1조: 포획사건을 조약과 일반적으로 승인된 국제법규에 따라 심판하는 것이 목적.
- 제2조: 1차 포획심판소, 2차 고등포획심판소의 2심 구조.
- 제3~4조: 심판관 자격에 판사·검사·변호사뿐 아니라 해군장교와 외무부 직원이 포함됨.
- 제6조: 포획심판소 검사 4인, 고등포획심판소 검사 3인.
- 제7조: 양 심판소는 법무부 소속이며 소장·심판관·검사는 대통령이 임면하고 보직은 법무부장관이 행함. 해군·외무부 인력의 겸직 가능.
- 제10조: 심판소 개설·폐지는 대통령령으로 정함.
- 제11조: 나포 함선 지휘관이 선박, 송치서, 나포조서, 선내 압수서류 등을 심판소에 넘기는 구조.
- 제12~15조: 검사 조사, 즉시석방 의견, 공고·소원 절차.
- 제21~24조: 고등포획심판소 항의/재심 구조.
- 제25조: 확정 심판 요지를 관보에 게재.
- 제26조: 불법나포 직접손해에 대해 석방심판 확정 후 국가 상대 손해배상청구 가능.
- 제27조: 포획 확정 물건은 국고 귀속.
- 제28~29조: 집행은 검사가 담당하고 해군은 나포물건 보관과 집행을 지원.
- 제31조: 시행 이전 발생 포획사건도 심판 가능.

따라서 평화선 집행은 `대통령 -> 해군 단속`이라는 단선이 아니라 최소 `해군 나포 -> 법무부 소속 심판소/검사 -> 대통령 임면 -> 외무부/해군 전문인력 참여 -> 관보 공고 -> 항의심 -> 국가배상 가능성 -> 검사의 집행 + 해군 지원`이라는 다기관 제도망이다.

## 정치인/행위자 노드 확장 방향

이번 원문은 이름보다 직책을 먼저 고정한다. 개인명을 추정하지 않는다.

- 대통령 이승만: 긴급명령 발령자이며 심판소 소장·심판관·검사의 임면권자. 구체 임명명단은 별도 원문 필요.
- 1952-10-04 법무부장관: 심판소 보직권을 가진 핵심 행정노드. 당시 재직자와 실제 보직행위를 관보/인사발령으로 검증할 것.
- 1952-10-04 국방부장관/해군총참모장 계열: 나포 함선 지휘·물건보관·집행지원의 기관 지휘선. 개인 직접명령은 별도 검증.
- 1952-10-04 외무부장관 및 외무부 고위직: 심판관 후보군 및 국제법/외교 연결노드.
- 포획심판소장·고등포획심판소장: 독립 정치/관료 노드 후보. 실제 임명자 식별이 최우선.
- 담당 검사·심판관: 나포 사건별 판단 주체. 첫 사건 기록에서 이름을 역추적한다.

## Adversarial checks

1. 포획심판령을 `평화선 선언 그 자체`로 보는 해석을 배제. 1/18 선언과 10/4 심판제도는 별도 법적 객체다.
2. `대통령이 나포한 선박을 직접 몰수`했다는 단순화를 배제. 나포 후 검사·심판소·항의 절차가 존재한다.
3. `해군만의 제도`라는 해석을 배제. 심판소는 법무부 소속이며 외무부 인력도 심판관 후보가 된다.
4. `사법적 통제 없음`이라는 해석을 배제. 2심, 소원, 공개변론 원칙, 불법나포 국가배상 조항이 존재한다.
5. 반대로 절차조항 존재를 실제 공정한 운용의 증거로 간주하지 않는다. 실제 사건기록/판결/외교항의로 검증해야 한다.
6. 1952-07-18 대통령 나포지시는 공식 원문 미확보 상태이므로 secondary claim으로 유지한다.
7. 제707호가 심판령과 같은 날 제정·시행된 것은 공식 법령검색으로 확인되나 실제 개설지/인사까지 자동 귀속하지 않는다.
8. 대통령기록관의 `1954-04-07 승인` 메타데이터를 실제 국회 의결일과 동일시하지 않는다. 국회회의록 확인 필요.
9. 긴급명령 제31조의 소급심판 가능성을 `소급처벌`과 동일시하지 않는다. 포획사건의 법적 성격과 적용 사례를 별도 검토한다.
10. 일본측의 국제법상 위법 주장을 한국 국내법의 무효와 동일시하지 않는다. 국내 법적 효력과 국제분쟁 주장을 분리한다.

## 직접 확인 문서/페이지 계수

이번 회차에서 검색결과 스니펫이 아닌 본문/원문 수준으로 직접 연 페이지는 9개로 계산한다: 대통령기록관 복원 컬렉션, 국가기록원 포획심판령 상세, 국가기록원 대통령긴급명령 주제목록, 국가법령정보센터 시행법령 결과, 동북아역사재단 포획심판령 전문 4개 구간, 국사편찬위원회 1952-01-18 관보 선언. 공식·공공 1차자료/원문 계열은 9개다. 동일 문서를 여러 구간 열람한 것은 문서 수로는 중복 제거하면 5개 고유 객체다.

이번 패스는 환경상 목표 40문서를 채우지 못했다. 대신 포획심판령 전문을 조문 단위로 직접 검증하여 기존 `선언` 중심 그래프를 `법무-해군-외무-대통령-국회` 집행·심판 그래프로 확장했다.
